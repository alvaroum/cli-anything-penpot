# Penpot CLI harness

This package exposes `cli-anything-penpot` and the `penpot` alias. It calls Penpot’s MAIN JSON RPC API rather than automating the browser or reimplementing Penpot.

Install the repository with `python3 -m pip install -e .`, or install the published Homebrew formula described in [`docs/homebrew.md`](../../../docs/homebrew.md). Python 3.11+ is required.

The package includes the AI-oriented `skills/SKILL.md`. The canonical source is `skills/cli-anything-penpot/SKILL.md` at the repository root.
